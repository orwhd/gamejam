# 01 — GDD CORE：核心玩法与状态循环

## 1. 核心定义

- **[已确认]** 主题：`Director's Cut`（Game Jam 主题，**不是已确认的正式游戏名**）。
- **[已确认]** 玩家控制一个角色，通过**删减 Persona 预设文字块**，改变角色记忆、性格倾向和 / 或可执行行为。
- **[已确认]** 删除经历不会改写世界历史；NPC 依然记得原本发生的事。
- **[已确认]** NPC 根据既定剧本行动；玩家通过实际操控自己的角色介入场景，使事件结果产生差异。
- **[已确认]** 玩家不仅编辑文字，还在场景中操控角色移动并与对象交互。

## 2. Persona 操作契约

| 项 | 规则 | 状态 |
|---|---|---|
| 编辑单位 | 由设计者预先划分的**文字块**，不是任意单词 | 已确认 |
| 可删除性 | 可按文字块分别设置 | 已确认 |
| 可重排性 | 设计者可规定哪些块允许重排；重排的具体玩法效应尚未定义 | 部分确认 |
| 身份 | 不通过删减改变当前操控角色的基本身份 | 已确认 |
| 删除经历 | 当前角色忘记该经历；其他人和世界历史不随之改变 | 已确认 |
| 删除后自动变强 | **不成立**；例如删掉整个 `not fireproof` 不自动让消防员获得防火能力 | 已确认 |
| 删除与性格 / 能力的映射算法 |  | 待决定 |
| 改 Persona 的时机（演出前 / 中 / 后） |  | 待决定 |
| 能否撤销 / 恢复文字块 |  | 待决定 |
| 重排后语义及作用 |  | 待决定 |

## 3. 交互契约

**[已确认]** 角色可移动，但 Persona 可阻止其执行具体交互。

**[示例]** 玩家控制消防员，试图进入发生火灾的建筑；由于角色认为必须服从上司命令，该交互不能执行。界面给出思想泡泡：

> I must obey my captain's orders.

- **[已确认]** 交互失败要能反映**角色的心理原因**，而不是让玩家以为按钮失灵。
- **[待决定]** 泡泡是否额外说明「因为与上司发生过不愉快的经历」。
- **[待决定]** 具体哪一个 Persona 文字块影响「进入建筑」交互，以及影响如何计算。
- **[已确认]** 删除相关过去经历仅让角色忘记；不保证自动反转所有属性，也不自动改变上司的记忆。

## 4. NPC 与结果

- **[已确认]** NPC 行动遵循预设的剧本；用户的原话是 NPC 都会去 act 一个剧本。
- **[已确认]** 玩家不能靠修改自己的记忆直接修改 NPC 的记忆或世界历史。
- **[已确认]** 同一事件能够因主角选择不同而得到不同结果。
- **[待决定]** NPC 面对门打不开、人员被提前救出等意外时的具体台词与反应。
- **[待决定]** 剧本的时间粒度、触发方式与重演机制。

## 5. 已提出的消防员关卡概念

**[已确认：概念级]**
- 主角为消防员；情境是灭火与营救。
- 上司的指令可以与消防员想做的行动冲突。
- Persona 可以包含一段**曾经被上司针对 / 与上司不愉快**的过去。
- 玩家可能通过删除经历改变消防员对上司的认知和行动。
- 需要呈现「原本不理想的结果」和「介入后较好的结果」的差异。

**[待决定：不得写死]**
- 这段经历的正式英文文本。
- 上司为什么针对消防员、具体发生过什么。
- 上司命令发出的时间、内容及后续行动。
- 建筑入口、救人、灭火的实际操作方式。
- 场景持续多久、火势如何发展。
- 关卡中的人物数量、对象清单与所有具体条件。

## 6. 可验证的基础玩法链路（不是强制时间安排）

以下是由已确认机制构成的**测试链路**，但交互顺序与编辑时机尚未最终确定：

1. 玩家尝试一个交互。
2. Persona 导致交互被阻止。
3. 角色通过思想泡泡表达自己为什么不愿意执行。
4. 玩家查看并删减预定义的 Persona 文字块。
5. 系统依据当前 Persona 状态重新计算交互是否允许。
6. 玩家再次操控角色参与现场事件。
7. 事件结果与未修改的演出可能不同。

**验收重点**：玩家能看出 Persona 的变化与实际交互的变化存在因果关系。

## 8. 当前原型设计边界

**应验证的核心：**
- 文字块编辑是否改变角色的记忆状态。
- Persona 对交互的影响是否可观察。
- 心理泡泡是否让玩家理解交互失败的原因。
- 主角改变行动后，NPC 仍有自己的剧本，但结局可以变化。
- 2.5D 空间中角色可以实际移动、交互（见 `02_SPATIAL_MATH.md`）。

**还未确定，不做成既成事实：**
- Persona 是否由 AI / LLM 实时解释。
- 特定能力值、性格数值、正负效果。
- 强制重置 / 轮回 / 回放模式。
- 角色移动自由度、输入方案和战斗玩法。
- 三星的最终玩法解法。
