## 1. 核心定义

- **[已确认]** 游戏正式名称：`Persona`；Game Jam 主题：`Director's Cut`。
- **[已确认]** 目标交付与操控：面向 Windows 提交（macOS 开发）；采用**键盘 + 鼠标**操作（键盘 `WASD` 控制角色移动、`E` 触发场景交互、`R` 随时重开，鼠标操作 `Pre-Take` 全屏 Persona 纸页与 UI 按钮）。
- **[已确认]** 当前交付范围：**优先集中完成第一个「消防员」关卡场景的完整闭环**（后续关卡尚未设定，当前阶段不制作「下一关」流转逻辑，仅保留手账结算卡重开冲星与完成演出闭环；本关详案见 [`08_LEVEL_01_FIREFIGHTER.md`](08_LEVEL_01_FIREFIGHTER.md)）。
- **[已确认]** 玩家控制一个角色，通过**删减 Persona 预设文字块**，改变角色记忆、性格倾向和 / 或可执行行为。
- **[已确认]** Persona 的效果判定采用**确定性规则 / 标签映射**（不接入 AI / LLM 实时解释，确保解谜因果可控且可离线运行）。
- **[已确认]** 进度范围：采用**单局 / 按关重开**结构，不设跨退出持久化存档。
- **[已确认]** 删除经历不会改写世界历史；NPC 依然记得原本发生的事。
- **[已确认]** NPC 根据既定剧本行动；玩家通过实际操控自己的角色介入场景，使事件结果产生差异。
- **[已确认]** 玩家不仅编辑文字，还在场景中操控角色移动并与对象交互。

## 2. Persona 操作契约

| 项 | 规则 | 状态 |
|---|---|---|
| 编辑单位 | 由设计者预先划分的**文字块**，不是任意单词 | 已确认 |
| 可删除性 | 可按文字块分别设置 | 已确认 |
| 可重排性 | 数据结构保留 `can_reorder` 扩展字段；**灰盒原型阶段不启用重排玩法**，当前关卡全部设为不可重排 | 已确认 |
| 身份 | 不通过删减改变当前操控角色的基本身份 | 已确认 |
| 删除经历 | 当前角色忘记该经历；其他人和世界历史不随之改变 | 已确认 |
| 删除后自动变强 | **不成立**；例如删掉整个 `not fireproof` 不自动让角色获得防火能力 | 已确认 |
| 删除与性格 / 能力的映射规则 | 每个文字块可显式绑定 `0..N` 个状态标签（可同时包含心理限制标签与正面认知/能力前提标签）；删除该块即同步移除其携带的所有标签，不自动赋予反向能力 | 已确认 |
| 改 Persona 的时机与界面形态 | **仅限每轮演出开始前（`Pre-Take`）在全屏纯文字 Persona 纸页编辑**（此时看不见 3D 房间）；点击 `ACTION!` 开始并切入 3D 房间进入 `Active Take` 后默认隐藏纸页并锁定编辑权限，现场碰壁后需重开（`Restart Take` / 按 `R` 键）退回 `Pre-Take` 全屏 Persona 纸页修改（`Active Take` 期间是否允许按 `Tab` 只读查看当前 Persona 见 [`07_UI_UX_SPEC.md`](07_UI_UX_SPEC.md) §5.4 `[待决定]`） | 已确认 |
| 能否撤销 / 恢复文字块 | **单轮演出内剪除后不可单独恢复**（保留划除痕迹）；只能通过「重开本轮演出（`Restart Take` / 按 `R` 键）」将整份 Persona 与场景状态完整重置回初始状态 | 已确认 |

> **与现有工程的差异提示（交接给编程 Agent）**：现有原型 `ADCDirector` 默认测试占位 `bAllowEditingDuringTake = true` 允许演出中途编辑，后续实现需按上述 `[已确认]` 规则收敛为“仅 `Pre-Take` 编辑 + `Restart Take` 整轮重置”（完整工程偏差对照见 [`08_LEVEL_01_FIREFIGHTER.md`](08_LEVEL_01_FIREFIGHTER.md) §11）。

## 3. 交互契约

**[已确认]** 角色可移动，但 Persona 可阻止其执行具体交互；缺少场景前置道具/条件时同样会拒绝对目标执行交互并给出反馈。

**[示例]** 角色试图进入某个受限空间时，由于心理限制不能执行该交互，界面给出思想泡泡：

> I must obey my captain's orders... Last time I disobeyed him, it ended badly.

- **[已确认]** 交互失败要能反映**角色的心理原因或缺少条件的原因**，而不是让玩家以为按钮失灵。
- **[已确认]** 心理受阻思想泡泡提示粒度：采用**「表层抗拒想法 + 隐晦指向过去经历的心理线索」**，引导玩家联想到去 Persona 审视对应记忆，但不直接点破应删除哪一个文字块。
- **[已确认]** 缺少场景前置道具/条件时的提示：同样可通过主角头顶英文思想泡泡吐槽反馈，与心理受阻保持同一种角色内省反馈语言。
- **[已确认]** 文档仅约束英文文本的结构与语义槽位，具体英文词句保持留空，留待后续在 UE 编辑器配置时填写微调。
- **[已确认]** 删除相关过去经历仅让角色忘记；不保证自动反转所有属性，也不自动改变他人的记忆。

## 4. NPC 与结果原则

- **[已确认]** NPC 行动遵循预设的剧本；玩家不能靠修改自己的记忆直接修改 NPC 的记忆或世界历史。
- **[已确认]** 即使主角在 `Pre-Take` 删除了自己的某段相关记忆、从而不再受心理限制阻拦，相关 NPC 的记忆、站位与既定态度依然按原剧本执行，改变的只是主角自身可执行的介入行为。
- **[已确认]** 同一事件因主角是否介入以及介入行动顺序的不同，会产生不同的客观结局与评价结果。
- 第一关中队长（Captain）与受困者（Civilian）的具体行为、三态演化及交互细则见 [`08_LEVEL_01_FIREFIGHTER.md`](08_LEVEL_01_FIREFIGHTER.md) §3–§6。

## 6. 核心演出循环（通用已确认阶段顺序）

1. **开始前准备（`Pre-Take` 全屏 Persona 纸页）**：呈现全屏纯文字 Persona 纸页（看不见 3D 房间，世界暂停），玩家审阅初始 Persona 文字块（首轮可直接不剪辑开始，也可先点击删减可编辑文字块）。
2. **正式进入演出（`Active Take` 切入 3D 房间）**：点击开始按钮（`WBP_ActionButton`）切入全屏 3D 室内透视平移跟随画面（相机离地高度、对地俯角与水平朝向恒定锁死，沿水平面平滑跟随主角并带边缘限位），隐藏 Persona 纸页并锁定编辑权限（场景层仅右上角保留低打扰 `[R] Retake` 键帽提示，见 [`07_UI_UX_SPEC.md`](07_UI_UX_SPEC.md) §5.1）；NPC 与场景危机开始按既定节奏演化。
3. **受阻线索反馈**：若当前 Persona 携带限制标签阻止某项交互（或缺少场景前置条件），按 `E` 时主角头顶弹出英文思想泡泡提供线索。
4. **重开重置（`Restart Take` / 按 `R` 键）**：玩家在碰壁或结算后按 `R` 键（或点击手账结算卡 `[R] Retake` 按钮），退回 `Pre-Take` 全屏纯文字 Persona 纸页，整份 Persona、角色位置、星容器、NPC 与场景全部状态完整恢复至初始状态。
5. **剪辑与再次开始**：玩家在 `Pre-Take` 全屏 Persona 纸页删掉对应的记忆文字块（本轮内保留划除痕迹且不可单独恢复），再次点击开始按钮切入 `Active Take`。
6. **介入改变结局**：限制标签消失后，玩家进入场景规划行动顺序与执行交互；达成目标或目标失效时触发即时闪现的星容器反馈，直至满足单轮结束条件进入结算。

**验收重点**：玩家能清晰感知「现场碰壁线索 → 按 `R` 退回全屏 Persona 纸页剪除记忆块 → 新一轮演出解锁交互并通过行动顺序规划改变结局」的因果闭环。

## 7. 动态星容器反馈与单轮结算通用机制（已确认）

### 7.1 非常驻即时闪现「星容器」UI 机制
- **非常驻显示**：星容器在 `Active Take` 中**不是**常驻屏幕的 HUD，仅在**已得星数增加（`EarnedStars`）**或**星容器上限扣减（`MaxStarContainers`）**的事件发生瞬间，于屏幕顶部居中**即时闪现提示**（约 2 秒后淡出），结算界面再完整展示最终结果。
- **动态容器上限语义**：
  - 每轮开始时按关卡目标总数预设初始空心星容器上限（如 `3` 个：`☆ ☆ ☆`）；
  - 当某个可挽救的局内目标**永久失效**（例如第一关受困者受伤失去无伤星、或身亡失去存活星）时，`MaxStarContainers` 实时扣减 `1`，UI 闪现对应空心星焦黑碎裂消失；
  - 已成功达成并结算的星数予以保留，不会因后续其他危机恶化而倒扣。

### 7.2 单轮演出（Take）自动结束条件
满足以下任一条件时，本轮演出立即结束并弹出手账结算卡（展示最终点亮星数、剩余容器、失去容器的焦黑残影及客观结果行）：
1. **达成当前容器满星**：`EarnedStars == MaxStarContainers`（由于每次目标永久失效都会同步扣减容器上限，只要把当前仍可挽救的全部目标完成，便会自然填满剩余容器并立即收工，避免空场卡死）。
2. **场景危机彻底失控**：到达关卡定义的终局失控阶段（如第一关 `RoomEngulfed` 火势铺满全屋），强制结束本轮演出并保留此前已达成的得分。

> 第一关《消防员》的 3 星具体点亮来源、容器扣减规则与 6 种客观结果完整对照表见 [`08_LEVEL_01_FIREFIGHTER.md`](08_LEVEL_01_FIREFIGHTER.md) §7。

## 8. 通用灰盒原型验收边界

- **编辑与重开闭环**：仅在 `Pre-Take` 全屏 Persona 纸页允许删减可编辑文字块；进入 `Active Take` 后隐藏并锁定编辑，单轮内不可单块恢复，仅通过 `Restart Take`（`R` 键或结算按钮）整轮重置。
- **确定性因果与提示**：NPC 不因主角删除记忆而改变历史或态度；交互被心理限制或前置条件拒绝时，通过锚定头顶 3D 坐标的屏幕空间思想泡泡给出准确线索，不令玩家误以为按键失灵。
- **2.5D 空间表现与 2D/3D 切换开关**：`Active Take` 全程采用定高、定俯角（`5°–15°`）、锁死水平朝向的 3D 室内透视平移跟随相机（`FOV 55°–65°`，水平 `X/Y` 平滑跟随 + 边缘 Clamp），封闭天花板并以朝镜头敞开的娃娃屋横切剖面衔接门外与室内；主角（及可选世界对象）在共用同一套底层逻辑的前提下提供 `VisualPresentationMode (Mesh3D_Placeholder / Paper2D)` 切换开关，支持先用 3D 占位救急跑通闭环，并随时一键切为底边中心接地的竖直 2D `Masked` 双面纸片对比视觉效果（见 [`02_SPATIAL_MATH.md`](02_SPATIAL_MATH.md) 与 [`05_ASSET_PIPELINE.md`](05_ASSET_PIPELINE.md)）。
- **第一关专项偏差与验收清单**：现有 `DirectorCutJam/` 工程重构对照表及第一关详细验收项以 [`08_LEVEL_01_FIREFIGHTER.md`](08_LEVEL_01_FIREFIGHTER.md) §11 为准。
