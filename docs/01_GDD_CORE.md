## 1. 游戏高概念与评委审美三大支柱 `[已确认]`

**一句话 High Concept**：
> 在一个由**童趣蜡笔涂鸦剪纸贴纸**构成的 2.5D 娃娃屋微缩舞台上，红高跟魔女队长、划火柴幻想吃烤鸡的小女孩、穿爱心裤衩尖叫的受困潮男与天使光环修狗撞进同一场荒诞火灾；你是幕后执剪的导演，在开演前用剪刀**划掉方脸消防员 Pipo 设定涂鸦本（Persona）里的特定记忆**——用“选择性失忆”帮他克服心理阴影与死板教条，但千万别手滑把他的灭火技能和负重腿力也一起剪掉！

### 支柱一：选择性失忆的「双刃剑博弈」（拒绝无脑全删）
- **核心洞察**：“删文字”如果只有解除限制的正面收益，玩家就会不读英文直接把所有可删句一键全删，解谜瞬间坍缩。
- **核心规则**：每页手账的可删词条由**「阻碍破局的负面包袱（童年/职场阴影、死板教条）」**与**「支撑行动的正面记忆（专业技能、日常锻炼）」**混排构成，且部分正面记忆伪装成搞笑宠物日常，部分负面教条伪装成专业铁律：
  - **剪对负面包袱** → 主角忘掉变青蛙的恐惧或迂腐守则，敢于做出违背常理的英雄壮举；
  - **误剪正面记忆** → 主角当场变成“把灭火器当烤鸡番茄酱瓶”或“抱不动裤衩哥直喘气”的呆萌失忆小人！
- **结果**：玩家必须结合舞台上的荒诞角色线索做外科手术般的 **`Director's Cut`（精准剪辑）**。

### 支柱二：蜡笔贴纸舞台的「荒诞反差幽默」（契合 `Director's Cut` 主题）
- **视觉与主题统一**：将 `Pre-Take` 打造为贴满手绘涂鸦的**「角色设定手账（Character Sketchbook — Director's Cut ✂️）」**，将 3D 房间打造为前侧敞开的**「娃娃屋纸偶舞台」**，所有角色均为带模切白边的蜡笔剪纸贴纸。
- **单向失忆喜剧**：剪掉主角记忆**不会改写世界历史**。门外的红高跟魔女依然举着星星魔杖威慑，屋角的卖火柴小女孩依然淡定划火柴想吃烤鸡；唯独“忘掉怕女巫”的方脸消防员夸着她的尖尖帽横冲直撞闯了进去，笑果拉满。

### 支柱三：「人设剪辑 × 空间动线」双层咬合（一关三幕反转）
- 4 天 Game Jam 集中全部美术与设计火力打磨 **1 个全明星登场的精品关卡**：
  - **第一幕（破门）**：剪除对红高跟魔女队长的恐惧 → 突破门外阻拦进入火场，却因“死板救援铁律”不敢先抱爱心裤衩伤员，被迫先灭火痛失无伤星（拿 `2/2` 星 + 1 颗焦黑碎星）；
  - **第二幕（试错）**：若盲目全删词条 → 虽能先救人，却忘掉天使修狗练出的腿力或把灭火器当成小女孩烤鸡用的番茄酱瓶，闹出大笑话无法满星；
  - **第三幕（封神）**：精准留优剪劣 → 冲入 S 形火场无伤抱起裤衩哥奔向门外天使修狗（`+2` 星），再折返拿灭火器轰开 `F1` 捷径全灭蜡笔烈火（`+1` 星），斩获 **`3/3` 完美演出**！

## 2. Persona 操作契约 `[已确认]`

| 维度 | 正式规则 |
|---|---|
| **编辑单位** | 设计者预设的**简短英文单句块**（每句 ≤16 词，确保评委 10 秒读完一整页），不可拆成单词 |
| **操作方式** | 仅启用**点击剪除（Cut）**；不启用词条重排（`can_reorder = false`） |
| **三类确定性标签** | 处于保留态（`PRESENT`）的词条赋予主角 `0..N` 个标签，删块即同步失去：<br>1. **心理/教条限制标签（`Limit.*`）**：阻止特定情境下的交互（删掉 = 解除束缚）；<br>2. **知识/技能前提标签（`KnowHow.*`）**：执行专业交互的必需前提（删掉 = 忘记怎么用道具）；<br>3. **体能/习惯修正标签（`Trait.*`）**：提供移速或效率加成（删掉 = 退回吃力慢速状态并冒吐槽泡泡） |
| **禁止反向超能力** | 删除词条**只移除其携带的标签**，绝不自动生成反向超能力 |
| **编辑时机与速览** | **仅限 `Pre-Take` 全屏手账纸页允许剪辑**；点击 `ACTION!` 进入 `Active Take` 后锁定编辑，**支持按 `Tab` 键半透明只读速览手账** |
| **撤销与重开** | 单轮内剪除后保留粗炭黑划除线且**不可单条恢复**；随时按 `R` 键（或点击结算卡 `[R] Retake`）整轮重置手账与舞台 |

## 3. 交互与冷幽默思想泡泡契约 `[已确认]`

当玩家在舞台上按 `E` 触发交互时，权威规则层返回 **4 类确定性表现**，全部通过主角头顶屏幕空间**思想泡泡（Thought Bubble）**传达：
1. **心理/教条受阻拒绝**：动作不执行，弹出指向对应记忆句子的角色抗拒气泡（如怕被魔女变青蛙、火没灭完不敢碰裤衩哥）。
2. **失忆乌龙 / 缺工具拒绝**：动作不执行，结合现场手绘角色弹出爆笑吐槽（如看着卖火柴小女孩头顶的烤鸡幻想，把灭火器误认成大号番茄酱瓶）。
3. **允许执行但带状态反馈**：动作正常执行，但若误删体能记忆则抱人移速暴跌并冒喘气气泡；首次突破拦门 NPC 时自动飘出俏皮打招呼气泡。
4. **舞台彩蛋互动**：对非阻塞叙事角色（如卖火柴小女孩）按 `E` 弹出趣味互动吐槽，让每个手绘角色都活起来！

## 4. 核心演出循环（4 步重玩心流） `[已确认]`

1. **`Pre-Take` 审阅与执剪**：在全屏角色设定涂鸦本上阅读 6 条短句，用剪刀划掉想让 Pipo 遗忘的句子，点击 `ACTION!`。
2. **`Active Take` 舞台介入**：一镜到底切入 3D 娃娃屋舞台操控蜡笔贴纸主角；中途可按 `Tab` 偷看手账，随时按 `R` 重开。
3. **碰壁顿悟 / 动态星容器闪现**：从思想泡泡与顶部闪现的焦黑碎星（`3→2` / `2→1`）中秒懂因果。
4. **`Take Result` 复盘冲星**：达成剩余容器满星或火满全屋时弹出手账结算卡，对照焦黑碎星残影与冷幽默评语点击 `[R] Retake` 冲击 `3/3` 满星！
