## 3. 2D 纸片出图硬性技术规范（防返工必看）

为适配 Unreal Engine 5.8 的 `Paper2D Sprite / Flipbook` 与 `Masked` 双面深度材质管线（详见 [`02_SPATIAL_MATH.md`](02_SPATIAL_MATH.md) 与 [`05_ASSET_PIPELINE.md`](05_ASSET_PIPELINE.md)），美工导出所有角色与场景纸片时必须遵守以下硬性要求：

1. **绘制视角：统一平视立绘（严禁画大俯视！）** `[已确认]`
   - 引擎中纸片保持严格竖直（平行于世界 Z 轴立于 3D 地面，不随相机俯角向后仰倒）。
   - 所有地面人物与独立道具统一按 **平视视角（微斜 3/4 正侧面或正侧面）** 绘制，双脚平齐踩在同一水平基线上，**严禁绘制俯视头顶透视**。
2. **边缘与透明通道：100% 干净硬切实边 PNG** `[已确认 / 技术必需]`
   - 导出格式：**RGBA 透明背景 PNG**。
   - 引擎使用 `Masked`（Alpha Test 二值硬裁剪）写入真实 3D 深度缓冲并投射阴影，因此**角色最外圈轮廓与全透明背景交界处必须是干净利落的实边**。
   - **严禁**外轮廓羽化、半透明柔边或发光渐变；**严禁**在角色脚底自带半透明灰黑椭圆阴影贴图（阴影由 3D 场景灯光实时投射）。
3. **锚点（Pivot）与画布尺寸统一** `[已确认]`
   - 地面人物与地面独立道具的基准点统一在 **底边正中心（Bottom-Center，即双脚接地中心点）**。
   - 同一角色的不同状态图、`2–4` 张小碎步序列帧以及**多角色合体状态纸片**（如护送合体纸片），必须采用**完全一致的画布像素尺寸与统一的脚底基线高度**，防止引擎切帧或单人/合体切换时出现抖动、偏移或悬空。
4. **水平镜像翻转转身（禁画文字字母）** `[已确认]`
   - 角色左右变向通过程序 **水平镜像翻转（Horizontal Flip）** 实现。
   - 服装、消防帽及手持工具上**不得绘制任何英文字母或数字**（可用对称几何图形徽章代替），防止翻转后出现反字穿帮。

## 4. 3D 室内环境技术风格规范

- **[已确认] 家具与装潢题材不作硬性锁定**：不需要固定死欧式或日式等具体家具题材风格，仅约束 **3D 空间与渲染技术风格**。
- **[已确认] 空间与镜头技术约束**（参考 `assets/example/envirments/example_0.png`）：
  1. **完整封闭的 3D 室内几何**：必须包含 3D 地板、侧墙/后墙与**封闭天花板**（严禁退回无顶高空俯视盒子）；
  2. **单固定室内透视机位同屏构图**：相机固定于房间左前方朝室内深处拍摄（`FOV 55°–65°`，轻俯角 `5°–15°`），透过**左墙敞开的门口/玄关**在同一固定镜头画面内同时呈现门外入口区、门外安全区与室内深处；
  3. **低矮隔断与动线可读性**：室内隔断与陈设保持低于角色肩部的低矮轮廓，配合关卡动线确保 `5°–15°` 轻俯角下纸片剪影与交互点清晰可读（第一关 S 形通道与侧角工具分岔布局见 [`08_LEVEL_01_FIREFIGHTER.md`](08_LEVEL_01_FIREFIGHTER.md) §4）；
  4. **衬托 2D 纯色纸片的可读性**：3D 墙地与陈设表面宜保持整洁概括的色块与柔和光影层次，避免高频杂乱噪点贴图干扰 2D 纯色无阴影纸片小人的轮廓识别，并准确承接 `Masked` 纸片的硬件深度前后遮挡与接地阴影。
