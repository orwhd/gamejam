# 02 — SPATIAL MATH：2.5D 纸片空间与娃娃屋跟随镜头契约

> 本文定义「3D 娃娃屋舞台 + 世界内 2D 竖直纸片 + 定高定角平移跟随相机」的空间与数学不变量。

---

## 1. 核心空间不变量 `[已确认]`

1. **真实 3D 舞台**：地板、墙壁、封闭天花板与低矮隔断均由真实 3D 几何构成；严禁建立脱离 3D 坐标系的假 2D UI 游戏世界。
2. **世界内竖直 2D 纸片**：玩家、NPC（含多角色合体护送状态）与可交互物品的可见表现均为立于 3D 世界中的二维纸片；火焰/水柱允许使用 2D 序列帧纸片或 3D 风格化特效。
3. **逻辑与渲染分离**：每个实体独立维护权威 3D 坐标 `WorldTransform`、物理碰撞体 `InteractionShape`（Capsule / Box）与视觉纸片 `VisualPlane`；切换纸片贴图绝不改变碰撞与交互判定。

---

## 2. 纸片接地、朝向与硬件深度遮挡 `[已确认]`

### 2.1 底边中心接地与竖直立面
对地面角色与地面道具，设脚底世界接触点为 `P_foot = (x, y, z)`，视觉平面局部向上向量 `V` 严格平行于世界 Z 轴 `(0, 0, 1)`：
- **Pivot 规则**：统一设在**底边正中心（`Bottom-Center`）**，使资产原点直接贴合 3D 地面 `P_foot`，单人态与合体护送态切换时严禁悬空或穿地。
- **不后仰原则**：无论摄像机向下俯视多少度，纸片始终**垂直于地面竖立（`Pitch = 0°, Roll = 0°`）**，正面平行于摄像机横向画面平面。
- **水平翻转转身**：角色沿左右方向变向时，采用材质 UV 或缩放**水平镜像翻转（Horizontal Flip）**切换朝向，不做薄纸板侧转隐身。

### 2.2 `Masked` 深度遮挡与屏幕空间提示
- **材质模式**：纸片统一采用 **`Masked`（Alpha Test 硬边裁剪）+ `Two-Sided`（双面）** 材质，真实写入硬件 Scene Depth 并投射阴影，与 3D 门框、隔断、前后角色及火焰自然形成准确遮挡。
- **屏幕空间投影 UI**：头顶思想泡泡（`WBP_ThoughtBubble`）与近距 `[E]` 交互键帽/环形读条（`WBP_InteractPrompt`）锚定世界 3D 挂点，通过 `ProjectWorldToScreen` 在屏幕空间正对玩家显示，确保英文清晰可读且不被墙体裁切。

## 3. 定高定角平移跟随相机与娃娃屋横切剖面 `[已确认]`

为同时满足**「室内封闭天花板纵深感（参考 `assets/example/envirments/example_0.png`）」「门外拦门戏剧冲突清晰居中」**以及**「室内 S 形通道与捷径一眼可读」**三大评委体验要求，`Active Take` 采用以下镜头与舞台契约：

### 3.1 相机四项核心规则（全程一镜到底，不切镜）
1. **离地高度恒定（`Z = const`）**：相机世界高度 `Z` 全程锁死在地板与封闭天花板之间（`Z_floor < Z_camera < Z_ceiling`），确保同屏同时看到封闭天花板底面、后墙/侧墙与地面。
2. **对地俯角恒定（`Pitch = const`，优化区间 `10° – 20°`）**：向下俯视角度锁死在 **`10° – 20°`**（UE Pitch `-10° ~ -20°`，推荐基准 `-15° ~ -18°`）。相比过浅的 `5°` 平视角，该区间既保留天花板纵深感，又能清晰拉开室内前后隔断 `B1 / B2` 的地面通道间隙，杜绝纸片前后叠成一团。
3. **水平朝向锁死（`Yaw = const, Roll = 0°`）**：相机绝不随主角转身旋转，始终正对前侧敞开的横切舞台平面。
4. **水平 `X/Y` 平滑平移跟随 + 边界限位（Clamp）**：相机按固定偏移沿左右横轴（`X`）与前后纵深轴（`Y`）带阻尼平滑跟随主角，并通过 `WorldXYClampBounds` 限位，防止穿墙或拍到舞台外黑边。

### 3.2 娃娃屋横切剖面衔接（门外 ↔ 室内无缝同台）
- **前墙统一敞开**：门外区域（出生点、拦门队长、安全区）与着火室内房间朝向镜头的一侧统一敞开，构成左右相连的微缩舞台盒。
- **中间隔墙开窗/剖面避让**：隔墙除开设门口 `D` 外，靠镜头前段做低矮剖面切口或开设宽大视窗，确保：
  1. 首轮主角在门外被队长拦住时，队长与主角处于画面黄金构图区，且玩家透过隔墙视窗即可同屏看清室内左侧受困者随火势扩张而受伤、倒下；
  2. 主角突破进门向右移动时，镜头丝滑横移展开 S 形火场与右前角灭火器，全程无墙体挡脸死角。

| 参数项 | 正式约束 |
|---|---|
| Projection / FOV | `Perspective`（3D 透视），`FOV 55° – 65°` |
| Camera Height `Z` | 恒定不变，满足 `Z_floor < Z_camera < Z_ceiling` |
| Camera Pitch | 恒定不变，向下俯视 **`10° – 20°`**（UE Pitch `-10° ~ -20°`） |
| Camera Yaw & Roll | `Yaw` 锁死正对舞台，`Roll = 0°` |
| Follow & Clamp | 沿世界 `X / Y` 平滑跟随主角 + 场景矩形边界 Clamp |
| 移动与碰撞 | 键盘 `WASD` 在 3D 水平地面八方向移动（无跳跃）；可扑灭火点带独立 3D 阻挡盒，扑灭即移除碰撞打通捷径 |

## 4. 空间体验验收清单

- [ ] `Active Take` 全程一镜到底平移跟随，高度 `Z`、俯角（`10°–20°`）与 `Yaw` 锁死不变，同屏可见封闭天花板、墙面与地面，边缘 Clamp 无穿墙露底。
- [ ] 娃娃屋横切舞台让门外拦门冲突构图饱满（不再挤在左边缘门缝），且门外受阻时能透过视窗看清室内受困者三态变化。
- [ ] 在 `10°–20°` 俯角与合理前后纵深间距下，玩家进门一眼即可看懂「S 形绕行主路」与「扑灭 `F1` 后的直通捷径」。
- [ ] 所有角色、合体护送态与道具均为 `Bottom-Center` 竖直 `Masked` 双面纸片，左右移动水平翻转，脚底严密接地，深度遮挡准确。
