# 02 — SPATIAL MATH：2.5D 空间与坐标契约

> **范围**：这份文档定义「3D 房间 + 世界内 2D 纸片」如何在同一场景中成立。
> 只确认用户描述过的空间目标。涉及数学的**坐标转换接口**属于技术契约，不暗示新的玩法规则。

## 1. 必须满足的空间事实

1. **[已确认]** 房间 / 场景由真实 3D 几何构成。
2. **[已确认]** 玩家角色与可交互物品的**可见部分**为二维纸片状。
3. **[已确认]** 特效允许采用 3D 方式，但灰盒阶段不要求制作正式特效。
4. **[已确认]** 摄像机构图参照用户提供的**第二张图**，而非当前第一张图的高空俯视盒子。
5. **[技术必需]** 角色与交互物品具有游戏世界中的位置，而不是固定在屏幕坐标上的贴图。
6. **[技术必需]** 交互检测、对象身份与对象的渲染组件应分离；换纸片显示不应改变交互对象本身。

## 2. 坐标层次（使用 Unreal 原生约定）

UE 世界坐标的技术基准：
- `World X, World Y`：水平位置分量。
- `World Z`：竖直高度。
- UE 默认世界坐标单位为 **厘米**；实际项目单位和比例尺需要核验。

**本原型不得引入另一个未经说明的独立「2D 游戏世界」。**

记录同一个世界对象的三个概念：

| 概念 | 含义 | 确定程度 |
|---|---|---|
| `WorldTransform` | 对象在 3D 场景的权威位置与朝向 | 技术必需 |
| `VisualPlane` | 贴在上述对象上的纸片表示 | 已确认视觉类型 |
| `InteractionShape` | 对象的物理交互 / 触发区域 | 具体形状待决定 |

### 2.1 地面角色与纸片显示的映射

对处于地板上的角色，记录：
- 逻辑位置 `P = (x, y, z)`。
- 地面接触点 `P_foot`（角色与当前地面的实际接触位置）。
- 纸片自身局部平面坐标 `(u, v)`。
- 局部水平方向单位向量 `U`。
- 局部竖直方向单位向量 `V`。

一个可用的**通用数学表达**：

`P_visual(u, v) = P_anchor + s_u * u * U + s_v * v * V`

约束：
- **[已确认]** 对地面站立角色与地面纸片对象，`V` 平行于世界向上方向 `(0, 0, 1)`，纸片竖直立于 3D 地面，**绝不随相机俯视角向后仰倒倾斜**。
- **[已确认]** 地面角色纸片的资产 Pivot 定在**底边中心（Bottom-Center）**接地，使 `P_anchor` 与脚底接地点 `P_foot` 对齐（或仅保留可控微调偏移）。
- **[已确认]** 纸片正面保持平行于摄像机横向画面平面；角色左右移动时通过**水平镜像翻转（Flip）**切换朝向。
- `s_u`, `s_v` 具体像素与厘米比例尺在编辑器灰盒校准中确定，此处不硬编码死值。

**不可把 `P_visual` 直接改成任意 UI 屏幕位置来跳过世界空间关系。**

### 2.2 交互物的映射

- 可交互物有自己的 `WorldTransform`。
- 其可见表示属于世界内的 `VisualPlane`（2D 纸片）。
- 交互体与视觉纸片属于**同一个逻辑对象**，但技术上可分别定位与偏移。
- 地面可交互物同样采用竖直纸片接地；贴墙交互物（如墙上消防栓/门）可依附墙面朝向配置。

### 2.3 世界坐标到画面、思想泡泡与交互提示

画面位置来自相机投影，而不是设计一个单独的 HUD 位置：

`ScreenPoint = Project(CameraViewProjection, WorldPoint)`

- 相机矩阵、对象视觉面、遮挡共同决定最终画面。
- **[已确认]** 头顶思想泡泡（Thought Bubble）：**锚定在角色头顶的世界 3D 坐标点，但投影至屏幕空间（Screen-space）朝向显示**，用于反馈心理受阻线索或缺少前置条件/工具的吐槽提示，确保英文文案清晰可读且不会被墙体裁切或因透视过度缩小。
- **[已确认]** 近距 `[E]` 交互提示（Interaction Prompt）：当玩家在 `Active Take` 中靠近处于可交互状态的世界对象进入触发范围时，锚定目标 3D 位置投影至屏幕空间显示 `[E]` 键帽（含按住交互的环形读条）；若对象切换为不可交互状态（例如目标失效），立即隐藏 `[E]` 提示（第一关具体交互挂点见 [`08_LEVEL_01_FIREFIGHTER.md`](08_LEVEL_01_FIREFIGHTER.md) §5 & §10.3）。

## 3. 摄像机与室内动线空间契约（已确认）

**已确认的阶段切换与主视觉镜头规范（对齐室内参考图 `assets/example/envirments/example_0.png`）：**
- **`Pre-Take` 与 `Active Take` 画面衔接**：`Pre-Take` 阶段为**全屏纯文字剧本页**（遮挡/不展示 3D 房间画面）；点击开拍进入 `Active Take` 后，切入下述**全程单固定室内 3D 透视机位**。
- **投影模式**：**3D 透视相机（`Perspective`）**。
- **全程单固定室内机位（演出期间不切镜头）**：机位固定于**房间前方偏左**，以**斜向轻俯视视角（Oblique View）**朝室内深处拍摄（朝向相机一侧的前墙敞开/剔除）。
- **FOV 范围**：约 **`55° – 65°`**。
- **俯仰角（Pitch）范围**：向下轻俯视约 **`5° – 15°`**（UE Pitch 约 `-5° ~ -15°`）。
- **室内与门外同屏空间要素及动线可读性**：
  1. 画面必须**同时能看到墙壁、天花板和地面**，呈现近大远小、空间纵深明显的室内场景；
  2. 参照参考图左墙房门结构，**透过敞开的门口/玄关在同一个固定镜头画面内直接看到门外入口区、阻拦点与门外安全区**，玩家进出房间及完成护送结算全程不切换摄像机；
  3. **室内动线与隔断约束**：室内隔断与障碍物须保持低于纸片肩部的低矮轮廓且保留明确可通行主通道，确保在 `5°–15°` 轻俯角下角色剪影与关键交互点不被遮挡（第一关《消防员》的 S 形多火点通道与侧角工具分岔布局详案见 [`08_LEVEL_01_FIREFIGHTER.md`](08_LEVEL_01_FIREFIGHTER.md) §4）；
  4. **严禁退回高空大俯角（如 `-58°`）无顶盒子跟随视角**。

| 参数 | 约束值 |
|---|---|
| Camera Projection | **[已确认]** `Perspective`（3D 透视） |
| Camera Mode | **[已确认]** 全程单固定机位（不切镜头、不绑玩家弹簧臂跟随），位于房间前方偏左朝室内深处拍摄 |
| 门外与室内衔接 | **[已确认]** 透过左墙/入口侧敞开的门口或玄关同屏呈现门外入口区与室内全景 |
| Camera Pitch（俯视角） | **[已确认]** 轻俯视 `5° – 15°`（UE Pitch 约 `-5° ~ -15°`） |
| FOV | **[已确认]** `55° – 65°` |
| Camera Exact Location (cm) & Yaw | 由编程 Agent 在灰盒关卡中按“同屏见墙、顶、地及左侧敞开门口”实测校准并开放编辑器微调 |

## 4. 平面朝向与转身规则（已确认）

- **[已确认]** 所有角色与地面物品纸片不得当作世界 XY 地板平面铺平（**现有工程地面扁平 `Cube` 标记必须替换**）。
- **[已确认]** 纸片在世界空间中保持**竖直（平行于世界 Z 轴）**，面朝镜头平面，不因相机 `5°–15°` 轻俯视而向后倾斜，保证脚底严丝合缝贴合地面。
- **[已确认]** 角色左右移动转身时，采用**水平镜像翻转（Horizontal Flip）**表现朝左/朝右，不做薄纸板侧转隐身。
- **[已确认]** 材质开启双面显示（Two-Sided），防止镜像或斜向观察时背面剔除消失。

## 5. 遮挡与排序不变量（已确认）

**[已确认 / 技术必需]**
- 纸片采用 **`Paper2D Sprite` 或平面 Mesh + `Masked`（Alpha Test 镂空双面、写入深度缓冲）材质**。
- 借助 `Masked` 材质真实写入 Scene Depth，纸片与 3D 墙壁、门框、前后角色及物品之间直接获得**准确的硬件 3D 深度遮挡与投影关系**，无需依赖脆弱的全局半透明手动排序。
- 不能用 UI 的显示顺序替代真实的世界深度。
- 火焰、烟雾、水柱等允许采用 3D 特效或带深度的表现，与纸片在同一 3D 空间内自然穿插遮挡。

## 6. 移动和碰撞边界（已确认）

- **[已确认]** 地面移动：支持键盘 **WASD 在 3D 水平地面（左右横轴 + 前后纵深轴）做平面四/八方向移动**；**不设跳跃**，无复杂三维平台跳跃行为。
- **[已确认]** 动态阻挡与多角色合体纸片移动：可清除的阻挡对象（如火点）附带 3D 碰撞体阻止直接穿过，被交互清除后同步解除该处碰撞阻挡；触发合体状态时（如第一关护送受困者），主角切换为单张合体 2D 纸片并共用主控 3D 碰撞体移动，进入目标区域触发器自动结算并恢复单人纸片（第一关护送与火点阻挡细则见 [`08_LEVEL_01_FIREFIGHTER.md`](08_LEVEL_01_FIREFIGHTER.md) §5）。
- **[技术必需]** 视觉纸片虽薄，角色与交互物的物理碰撞体仍采用稳定的 3D 体（如胶囊体 `Capsule` / 盒体 `Box`），以保证与 3D 墙体和交互区域的碰撞稳定。
- 移动速度、碰撞体半径与交互触发距离的具体厘米数值可在编辑器中配置微调。

## 7. 灰盒空间验收清单（供编程 Agent 与设计 Agent 分离验收）

- [ ] `Pre-Take` 为全屏纯文字剧本页；点开拍进入 `Active Take` 后全程采用单固定室内 3D 透视摄像机（`FOV 55°–65°`，轻俯视 `5°–15°`，位于房间前方偏左朝深处拍摄），画面同时可见墙壁、天花板与地面，彻底移除原弹簧臂 `-58°` 高空俯视盒子视角。
- [ ] 透过敞开的门口/玄关在同一固定镜头内可直接看到门外入口区、安全区与室内全景，进出门与目标区结算全程无切镜。
- [ ] 玩家角色、NPC 与可交互物均以世界内竖直 2D 纸片（底边中心接地、`Masked` 双面材质写深度）站在 3D 地面或依附墙面上，替换原有 3D 球体/方块与地面扁平标记板。
- [ ] 角色通过 WASD 在水平地面四/八方向移动时，脚底与地面严密贴合，左右变向呈现水平镜像翻转（Flip），视觉位置与碰撞/交互位置一致；合体状态纸片切换与动态阻挡碰撞解除正常。
- [ ] 纸片与 3D 墙壁、门框、前后人物及火焰/特效之间具备准确的真实深度遮挡关系。
- [ ] 头顶思想泡泡与近距 `[E]` 交互提示锚定 3D 坐标并以屏幕空间朝向显示，英文清晰可读且不被墙体裁切（不可交互状态自动隐藏 `[E]` 提示）。
- [ ] 第一关专属 S 形火点通道、侧角工具摆位及合体护送验收见 [`08_LEVEL_01_FIREFIGHTER.md`](08_LEVEL_01_FIREFIGHTER.md) §11。
