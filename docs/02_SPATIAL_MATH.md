# 02 — SPATIAL MATH：3D 空间与坐标契约

> **范围**：这份文档定义全 3D 场景（房间、人物、NPC、可交互物均为 3D 模型）中的坐标、锚点、摄像机、遮挡与移动约束。
> 只确认用户描述过的空间目标。涉及数学的**坐标转换接口**属于技术契约，不暗示新的玩法规则。
>
> **变更记录**：用户已明确作废旧版「人物与可交互物为 2D 纸片」规则，改为《多罗与流星》PS2 风格简化卡通 3D（见 `06_ART_DIRECTION.md`）。纸片相关的朝向、Flip、`Masked` 双面材质规则一并作废。

## 1. 必须满足的空间事实

1. **[已确认]** 房间 / 场景、人物、NPC、可交互物均由真实 3D 模型构成。
2. **[已确认]** 特效允许采用 3D 方式。
3. **[已确认]** 摄像机构图参照用户提供的**第二张图**（仅参考构图与空间关系），而不是图一的高空俯视盒子。
4. **[技术必需]** 角色与交互物品具有游戏世界中的位置，而不是固定在屏幕坐标上的贴图。
5. **[技术必需]** 交互检测、对象身份与渲染组件分离；替换模型（灰盒占位 → 正式美术）不应改变交互对象本身。

## 2. 坐标层次（使用 Unreal 原生约定）

- `World X, World Y`：水平位置分量；`World Z`：竖直高度。
- UE 默认世界坐标单位为 **厘米**。

| 概念 | 含义 | 确定程度 |
|---|---|---|
| `WorldTransform` | 对象在 3D 场景的权威位置与朝向 | 技术必需 |
| `VisualMesh` | 挂在上述对象上的 3D 模型表现（灰盒占位或正式美术） | 已确认视觉类型 |
| `InteractionShape` | 对象的物理交互 / 触发区域 | 具体尺寸由编辑器配置 |

### 2.1 地面角色与模型的映射

- **[技术必需]** 角色模型的原点位于**脚底接地中心**，使模型脚底与角色在地面上的接触点 `P_foot` 对齐，不悬空、不穿地。
- **[技术必需]** 模型与碰撞胶囊体之间若存在偏移，必须固定且可追踪。
- **[待决定]** 角色转身表现（随移动方向旋转模型的方式与速度），见 `06_ART_DIRECTION.md`。

### 2.2 交互物的映射

- 可交互物有自己的 `WorldTransform`，可见表现为 3D 模型。
- 交互体与视觉模型属于**同一个逻辑对象**，技术上可分别定位与偏移。
- 地面物体原点在底面接地中心；贴墙物体（如门）按附着面配置原点。

### 2.3 世界坐标到画面与思想泡泡

`ScreenPoint = Project(CameraViewProjection, WorldPoint)`

- **[已确认]** 头顶思想泡泡：**锚定在角色头顶的世界 3D 坐标点，投影到屏幕空间（Screen-space）显示**，保证英文清晰可读，不被墙体裁切，也不会因透视缩得过小。

## 3. 摄像机契约（已确认）

- **投影模式**：**3D 透视相机（`Perspective`）**。
- **全程单固定室内机位（不切镜头）**：位于**房间前方偏左**，以斜向轻俯视视角朝室内深处拍摄（朝向相机一侧的前墙敞开 / 剔除）。
- **FOV**：约 **`55° – 65°`**；**俯视角**：约 **`5° – 15°`**（UE Pitch 约 `-5° ~ -15°`）。
- **同屏空间要素**：
  1. 画面同时能看到墙壁、天花板和地面，近大远小、纵深明显；
  2. 透过敞开的门口 / 玄关，在同一个固定画面里直接看到门外入口区、双手撑开拦门的队长以及门外安全区，进出房间不切换摄像机；
  3. **严禁退回图一的高空大俯角（如 `-58°`）无顶盒子跟随视角**。

| 参数 | 约束值 |
|---|---|
| Camera Projection | **[已确认]** `Perspective` |
| Camera Mode | **[已确认]** 全程单固定机位（不切镜头、不绑玩家弹簧臂） |
| 门外与室内衔接 | **[已确认]** 透过敞开的门口同屏呈现 |
| Camera Pitch | **[已确认]** 轻俯视 `5° – 15°` |
| FOV | **[已确认]** `55° – 65°` |
| Camera Exact Location (cm) & Yaw | 由编程 Agent 在灰盒关卡中实测校准，并开放编辑器微调 |

## 4. 遮挡与渲染

- **[技术必需]** 角色与物体均为不透明 3D 模型，依靠场景深度获得前后遮挡，不需要手动排序层级。
- 不能用 UI 的显示顺序替代真实的世界深度。
- 火焰、烟雾、水柱等 3D 特效与模型在同一空间内自然穿插遮挡。
- 着色风格（柔和明暗 / 纯色块、无描边）见 `06_ART_DIRECTION.md`。

## 5. 移动和碰撞边界（已确认）

- **[已确认]** 键盘 **WASD 在 3D 水平地面做四 / 八方向移动**；**不设跳跃**。
- **[技术必需]** 角色与交互物使用稳定的 3D 碰撞体（如 `Capsule` / `Box`）。
- 移动速度、碰撞体半径与交互触发距离的厘米数值在编辑器中配置。
