## 3. Pivot / Anchor 与转身合同（已确认）

### 3.1 地面角色与 NPC
- **[已确认]** **底边中心接地（Bottom-Center Pivot）**：人物纸片的 Pivot 统一设在底边中心，与角色在 3D 地面上的脚底接触点对齐。
- **[已确认]** **竖直立面**：纸片绕水平轴不倾斜（即使摄像机存在 `5°–15°` 轻俯视，纸片依然垂直于地面竖立），杜绝脚底悬空或穿地。
- **[已确认]** **水平翻转转身**：角色在左右方向改变移动朝向时，通过水平镜像翻转（Flip）切换朝向。

### 3.2 场景可交互物
- **[已确认]** 地面独立可交互物采用相同的底边中心接地竖直纸片规则；墙面附着物（如门、墙挂灭火器）按附着面配置锚点。
- **[技术必需]** 纸片的可见位置与其实际交互对象绑定；3D 碰撞/触发体独立于纸片厚度。

## 4. 材质遮挡与渲染深度规则（已确认）

- **[已确认]** 角色与物品纸片统一使用 **`Masked`（二值镂空裁剪）+ `Two-Sided`（双面）材质**。
- **技术收益**：`Masked` 材质直接写入硬件深度缓冲（Depth Buffer）并支持投射 3D 阴影，可与 3D 墙壁、门框、天花板及前后不同景深的纸片角色自然形成真实遮挡，无需手动维护复杂的半透明层级表。
- **[已确认]** 头顶思想泡泡采用锚定 3D 头顶坐标的屏幕空间投影显示，始终清晰可读；非常驻星容器提示与 Persona 面板位于屏幕 UI 层。
