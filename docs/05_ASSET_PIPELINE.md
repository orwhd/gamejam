# 05 — ASSET PIPELINE：3D 资产类型、锚点、命名与接入接口

> 美术风格见 `06_ART_DIRECTION.md`（《多罗与流星》PS2 简化卡通 3D）。
> **分工**：设计 Agent 负责美术资产的风格、设定与制作交付；编程 Agent 只负责按本文规范接入资产，并用技术占位几何体推进灰盒，不得自行创作美术资产。
> **变更记录**：旧版 2D 纸片（`Paper2D Sprite`、`Masked` 双面、底边中心纸片、水平 Flip）规则已由用户作废。

## 3. 锚点（Pivot）合同

- **[技术必需]** 角色模型原点在**脚底接地中心**，正面朝向 UE 的 `+X` 方向，统一比例为厘米。
- **[技术必需]** 地面道具原点在底面接地中心；贴墙道具（如门）原点在附着面 / 门轴处。
- **[技术必需]** 模型的可见位置与交互对象绑定；碰撞 / 触发体独立配置。
- 队长「双手撑开拦门」是 3D 姿势 / 动画，具体制作方式随动画方案决定。

## 4. 材质与渲染

- **[已确认]** PS2 时代低面数 + 简单柔和明暗 / 纯色块，**不加描边**。
- 不透明模型依靠场景深度遮挡，无需手动排序。
- 具体材质方案（顶点色 / 纯色 / 少量手绘贴图）待决定，见 `06_ART_DIRECTION.md`。

## 5. 交付与接入接口

| 项 | 规范 |
|---|---|
| 交付方 | 设计 Agent（美术） |
| 接入方 | 编程 Agent：替换灰盒占位几何体，不改变逻辑对象与交互体 |
| 占位替换原则 | 灰盒占位与正式模型的原点、朝向、比例保持一致，替换后交互范围不变 |
| 面数预算、贴图分辨率、导出格式 | 待决定 |

## 6. 资源验收清单

- [ ] 室内有完整的地板、侧墙 / 后墙、敞开门口与天花板，在单固定机位下同屏呈现室内纵深与门口拦路区。
- [ ] 消防员、无台词拦门的队长、受困者都是人类、圆润大头的低面数 3D 角色，轮廓在固定机位下能一眼区分。
- [ ] 着色为柔和明暗或纯色块，没有描边，没有残留像素画风格。
- [ ] 模型原点在脚底 / 底面接地中心，不悬空、不穿地。
- [ ] 新增资产遵循第 2 节命名前缀。
- [ ] 灰盒占位替换为正式模型后，交互范围与逻辑不变（由编程 Agent 验证）。
