## 3. Pivot / Anchor 与转身合同（已确认）

### 3.1 地面角色、NPC 与合体状态纸片
- **[已确认]** **底边中心接地（Bottom-Center Pivot）**：人物纸片的 Pivot 统一设在底边中心，与角色在 3D 地面上的脚底接触点对齐。
- **[已确认]** **多角色合体状态纸片规范**：合体状态纸片（如第一关「消防员 + 受困者」护送纸片）必须与单人纸片共用**统一的画布尺寸、`Bottom-Center` Pivot 与脚底基线高度**，保证单人/合体切换时脚底不悬空、不偏移。
- **[已确认]** **竖直立面**：纸片绕水平轴不倾斜（即使摄像机存在 `5°–15°` 轻俯视，纸片依然垂直于地面竖立），杜绝脚底悬空或穿地。
- **[已确认]** **水平翻转转身**：角色在左右方向改变移动朝向时，通过水平镜像翻转（Flip）切换朝向。

### 3.2 场景可交互物
- **[已确认]** 地面独立可交互物采用相同的底边中心接地竖直纸片规则；墙面附着物（如门、墙挂道具）按附着面配置锚点。
- **[技术必需]** 纸片的可见位置与其实际交互对象绑定；3D 碰撞/触发体独立于纸片厚度。

## 4. 材质遮挡与渲染深度规则（已确认）

- **[已确认]** 角色与物品纸片统一使用 **`Masked`（二值镂空裁剪）+ `Two-Sided`（双面）材质**。
- **技术收益**：`Masked` 材质直接写入硬件深度缓冲（Depth Buffer）并支持投射 3D 阴影，可与 3D 墙壁、门框、天花板及前后不同景深的纸片角色自然形成真实遮挡，无需手动维护复杂的半透明层级表。
- **[已确认]** 头顶思想泡泡与近距 `[E]` 提示采用锚定 3D 坐标的屏幕空间投影显示，始终清晰可读；非常驻星容器提示、右上角低打扰 `[R] Retake` 提示与手账层 Persona 纸页/结算卡位于屏幕 UI 层。

## 6. 灰盒资源验收清单（通用管线）

- [ ] 室内灰盒具备完整的 3D 地板、侧墙/后墙、敞开门口与**封闭天花板**，在 `FOV 55°–65° / 恒定俯角 5°–15° / 恒定离地高度` 的平移跟随相机与娃娃屋前侧敞开横切剖面下，顺畅衔接门外入口区与室内纵深且无墙体遮挡死角。
