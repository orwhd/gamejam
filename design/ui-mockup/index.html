版式与状态

  • 全屏奶油色剧本纸，压在暖棕桌面上；胶带角为纯色

  • 已删：粗马克笔线划掉，原文保留；本轮内不能恢复

  • 开拍后去掉所有大块面板，只常驻右上角 Take 场记牌
  • 单固定室内机位；透过左墙敞开的门，同一画面看到门外撑手拦门的队长和蓝色安全区

思想泡泡

  • 奶油底 + 桃橙粗描边 + 大圆角；圆点尾巴
  • 文案结构：表层抗拒想法 + 隐晦的过去经历线索（第二行字号小一些）
  • 锚定头顶 3D 坐标、屏幕空间显示；弹出时回弹，数秒后缩小消失

[E] 提示

  • 圆胖键帽 + 动词标签，出现在可交互目标上方，轻微弹跳

  • 屏幕顶部居中，事件触发时弹出，约 2 秒后淡出

  • 扣减：最右空心星 → 焦黑 → 裂开 → 卡通烟 → 消失（搞笑而非恐怖）
  • UI 只订阅 EarnedStars / MaxStarContainers 变化，不自己计算

组件规则

  • 所有组件：纯色填充 + 暖墨黑手绘描边 + 大圆角
  • 禁止：渐变、毛玻璃、写实投影、霓虹发光、赛璐璐硬阴影
  • UI 中可以出现英文（UI 不做镜像翻转）；世界内的纸片仍然禁止字母和数字
  • 动效：短促回弹，单段约 0.3–0.5 秒；时长开放给编辑器配置

字体

  • 示意字体：Courier Prime / Fredoka / Patrick Hand（均为 OFL 授权）；最终选型 [待决定]
