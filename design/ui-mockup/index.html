手账纸页与去片场化

  • 全屏奶油色手账纸页 + 四角纯色胶带贴角
  • 简洁页眉：只保留标题与关卡名，去掉场次号、拍数递增与主题红印章
  • 正文采用自然手账段落（圆润无衬线体），不用好莱坞剧本格式或打字机字体

文字块三态

  • 固定：普通暖墨黑，无悬停
  • 可删：荧光笔底色 + 虚线；悬停转腮红粉、光标变剪刀
  • 已删：粗马克笔划除并保留原文痕迹；本轮内不能恢复

开始行动（WBP_ActionButton）

  • 大圆角纯色按钮「ACTION!」：短促回弹按下 → 纸页收起 → 进入 Active Take 并锁定编辑

[E] 提示

  • 圆胖键帽 + 动词标签，出现在可交互目标上方，轻微弹跳

读条为水蓝色环形 = 喷水

按住 E 灭火读条

  • 沿键帽外圈的水蓝环形进度（语义：在喷水）
  • 松手中断时按火点保留已喷进度（不清空）；保留进度是否随时间缓慢回退或随火势升阶增加所需量 [待决定·08 §12]

非常驻星容器闪现

  • 屏幕顶部居中，事件触发时弹出，约 2 秒后淡出
  • 空心：奶油底 + 墨线；点亮：奶油黄 + 弹跳闪点
  • 扣减：最右空心星 → 焦黑 → 裂开 → 卡通烟 → 消失（搞笑而非恐怖）
  • UI 只订阅 EarnedStars / MaxStarContainers 变化，不自己计算

手账结算卡（去片场化）

  • 大圆角奶油白手账卡 + 纯色胶带贴角，去掉场记板合拍、小黑板外框、结算口令与拍数编号

组件与禁令

  • 所有组件：纯色填充 + 暖墨黑手绘描边 + 大圆角
  • 严禁视觉：渐变、毛玻璃、写实投影、霓虹发光、赛璐璐硬阴影
  • 严禁片场道具：场记板造型与合拍动效、主题红印章、好莱坞剧本格式与打字机等宽字体、右上角场记牌、场次/拍数递增编号与结算喊卡口令
  • UI 中可出现英文；世界内纸片仍禁止字母和数字

字体与动效

  • 示意字体：Fredoka / Patrick Hand（均为 OFL 授权）；最终选型 [待决定]
  • 动效：短促回弹，单段约 0.3–0.5 秒；时长开放编辑器配置
